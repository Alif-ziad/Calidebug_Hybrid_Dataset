# CaliDebug Hybrid Dataset

Repository reserved for the **CaliDebug Hybrid** code-debugging dataset used in my LLM code-repair experiments.

## Current public status

At the time of this documentation update, the default branch exposed through GitHub contains this README but does **not expose the dataset files themselves**. For that reason, this repository should not yet be cited as a downloadable/reproducible public dataset release.

## Intended role

The dataset is used for experiments involving:

- Buggy-to-fixed code pairs
- LLM fine-tuning for code repair
- QLoRA baselines
- Retrieval-augmented repair experiments
- Model comparison and error analysis

## Before treating this as a dataset release

A proper public release should include or link to:

1. Versioned train/test files.
2. Column/schema documentation.
3. Dataset construction and cleaning procedure.
4. Split methodology and leakage controls.
5. License/provenance information.
6. Checksums/version identifiers for the exact files used in experiments.

Until those are published, this repository is best treated as a project placeholder/documentation entry rather than the canonical dataset artifact.
